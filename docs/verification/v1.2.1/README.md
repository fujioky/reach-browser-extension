# 1.2.1 升级迁移验证

在 1.2.0 的统一自适应登录基础上，FUJIOKY 地址保存的旧管理员 `reach_` 连接必须重新通过独立应用网页登录。第一次状态检查或分享时在发出请求前阻断旧令牌，原有 UI 自动回到登录页。非 FUJIOKY 地址保留原密码令牌。

不会删除服务器上原有 API 令牌，不影响既有脚本；新扩展设备都进入中央授权管理。旧手填 `member_reach_` 令牌由服务端拒绝，需重新登录。

新增迁移回归与此前测试合计 72 项通过；TypeScript、双浏览器构建及实际 Chromium 设置页通过。浏览器授权成功仍使用隔离夹具，实际生产授权与撤销见 Reach 后端报告；Firefox 未做实机验收/AMO 签名。

原设计与行为证据见 [1.2.0](../v1.2.0/README.md)。安装包 SHA-256 在发布的 `SHA256SUMS`。
